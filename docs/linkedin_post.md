## Variant A — O'zbekcha

📚 Kitob o'qishni kursga aylantiradigan ilova yaratdim — **Learner**

Ko'pchiligimizda "o'qishim kerak" degan kitoblar ro'yxati bor. Muammo — vaqt emas, ko'pincha kitobning og'irligi: qalin matn, notanish atamalar, boshqa tilda yozilgan.

Learner'ga PDF tashlaysiz, u esa:
✅ kitobni boblar va kichik qismlarga bo'ladi
✅ har bir qismni o'zingiz tanlagan tilda sodda tushuntiradi — hech narsani tashlab ketmasdan
✅ bob oxirida savol-javob, quiz va mashqlar beradi (javoblaringizni Claude tekshiradi)
✅ "Ustoz" paneli savolingizga kitobdan qidirib javob beradi va qaysi bob, qaysi sahifadan olinganini ko'rsatadi

🌐 Interfeys uch tilda: o'zbek, ingliz, rus. Interfeys tili va o'rganish tili alohida tanlanadi — masalan, inglizcha kitobni o'zbekcha tushuntirish bilan o'qish mumkin.

🛠 Texnik tomoni: Flutter (Windows desktop), Claude (Claude Code CLI yoki Anthropic API), SQLite FTS5 asosidagi RAG qidiruv, API kalit Windows DPAPI bilan shifrlanadi.

Ilova bepul va ochiq kodli (MIT). Windows uchun installerni GitHub'dan yuklab olishingiz mumkin 👇
https://github.com/Alfraganus/learner/releases/latest

Sinab ko'ring va fikringizni yozing — qaysi kitobdan boshlagan bo'lardingiz? 🙌

## Variant B — English

📚 I built an app that turns any book into a guided course — meet **Learner**

Most of us have a "should read" list. Often the blocker isn't time — it's the book itself: dense text, unfamiliar terms, or a language that isn't your first.

Drop a PDF into Learner and it:
✅ splits the book into chapters and bite-sized parts
✅ explains every part simply in the language you choose — without skipping anything
✅ ends each chapter with Q&A, a quiz and exercises (Claude grades your answers)
✅ has a Tutor panel that answers your questions from the book and cites the exact chapter and page

🌐 The interface speaks Uzbek, English and Russian. Interface language and learning language are set separately — read an English book with explanations in Uzbek, for example.

🛠 Under the hood: Flutter (Windows desktop), Claude (Claude Code CLI or the Anthropic API), RAG search on SQLite FTS5, API key encrypted with Windows DPAPI.

It's free and open source (MIT). Grab the Windows installer on GitHub 👇
https://github.com/Alfraganus/learner/releases/latest

I'd love your feedback — which book would you start with? 🙌

## Variant C — Русский (короткий)

📚 Сделал приложение, которое превращает любую PDF-книгу в пошаговый курс — **Learner**.

Книга делится на главы и небольшие части, каждая объясняется простыми словами на выбранном языке. В конце главы — вопросы, тест и упражнения, а «Наставник» отвечает на вопросы по книге со ссылкой на главу и страницу.

Интерфейс на узбекском, английском и русском. Бесплатно, открытый код (MIT), установщик для Windows:
https://github.com/Alfraganus/learner/releases/latest
